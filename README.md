# ARCANA Forensics

Offline-first digital forensics triage and incident response suite.

## Features
- **Air-Gapped Operation:** Zero cloud dependencies and no outbound network telemetry.
- **Evidentiary Integrity:** Automated cryptographic SHA-256 evidence manifest logging.
- **Fast Live Triage:** Automated artifact extraction across memory, event logs, and file systems.
